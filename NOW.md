# NOW

## Current role

ENA Field Guide is the downstream home for **practical, evidence-backed ENA HOW**.

It does not mirror ENA theory and it does not own general Human-AI project-working method.

```text
ENA research / evidence
-> practical operating pattern earns reuse
-> Field Guide HOW
```

## Current admission state

No standalone HOW entry has been admitted yet.

That is intentional. The repository should not grow merely because upstream ENA has many interesting mechanisms or because a research result sounds actionable.

A candidate entry must still satisfy the README admission rule:

- recurring or materially real problem;
- concrete reusable action;
- evidence/reality contact beyond attractive theory;
- applicability boundary or counterexample;
- monitoring/failure conditions;
- practical value beyond the originating experiment/session.
